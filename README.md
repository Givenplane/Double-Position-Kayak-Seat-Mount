# Double-Position Kayak Seat Mount

Dual-position kayak seat mounting system with two selectable seating heights.
Designed to accommodate commercially available kayak seats.

## Project status

STL and STEP models, a bill of materials and an illustrated assembly guide are available.
Exact seat compatibility, mounting dimensions and height difference remain to be documented for the reference configuration.

## Repository structure

- `3d_models/STL/` — printable part files.
- `3d_models/STEP/` — editable CAD exchange files.
- `images/` — project photographs, diagrams and assembly views.
- `docs/` — bill of materials and technical documentation.

## 3D printing recommendations

- **Reference material:** PETG.
- **Alternative materials:** other engineering-grade filaments may be used, provided they are suitable for the mechanical loads and operating environment and the finished parts retain the required fit.
- **Infill:** 100%.
- **Infill pattern:** rectilinear.
- **Post-processing:** annealing is recommended. Follow the filament manufacturer's annealing guidance for the selected material; no universal temperature or duration is specified here. Recheck dimensions and seat-foot fit after annealing, since heat treatment can change part dimensions.
